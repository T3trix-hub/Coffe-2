# Кофейня №2 — сайт

Многостраничный статический сайт для кофейни №2 (Минск, Прилукская ул., 60). Чистые HTML, CSS и JavaScript, без сборки.

## Страницы
- `index.html` — главная: рейтинг, чем хвалят гости, удобства, выпечка
- `menu.html` — меню
- `gallery.html` — галерея с просмотром фото
- `contacts.html` — адрес, телефон, Instagram, карта

## Структура
`style.css`, `main.js` (меню, плавное появление), иконки `favicon*` и `apple-touch-icon.png`, фото в `images/`.

## Запуск
`python3 -m http.server 8000` и открыть http://localhost:8000

## GitHub Pages
Загрузите содержимое папки в корень репозитория, затем Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Что править
- **Цены** — `menu.html`: замените `<span class="pr ask">цену уточняйте</span>` на `<span class="pr">6 Br</span>`. Сейчас указаны только капучино (7–8 Br) и миндальный круассан (7.5 Br) из Яндекс Карт.
- **Телефон** — футер каждой страницы и `contacts.html`.
- **Время работы** — не указано (на картах нет точных данных), добавьте в `contacts.html`.
- **Цвета** — переменные в начале `style.css`.
- **Шрифты** — Roboto Slab и Manrope (Google Fonts).

Данные взяты с карточки на Яндекс Картах, фото предоставлены для проекта.
